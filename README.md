NOVARJ7 RP

Servidor brasileiro de GTA San Andreas Multiplayer (SA-MP).

Objetivo

Criar uma cidade de roleplay com sistemas de vida real.

Sistemas planejados

- Cadastro e login de jogadores
- Criação de personagens
- Dinheiro e economia
- Empregos e salários
- Polícia e prefeitura
- Casas e veículos
- Salvamento de dados

Desenvolvimento

Projeto desenvolvido pelo Android, com foco em ferramentas gratuitas.

Status: Em desenvolvimento.
